# Due

Consistency-first marathon training app. **This is the extraction rebuild** of
[`jakesellison/mileage`](https://github.com/jakesellison/mileage) — see
`docs/specs/2026-07-29-due-extraction-rebuild-design.md` for the method and
`docs/PROGRESS.md` for where it stands.

- `CLAUDE.md` — the agent constitution (layer law, arrival paths, rules)
- `MISSING.md` — everything deliberately left behind, one line each
- `checks/` — the machine-enforced invariants (`npm run check`)

Until cutover, the old repo remains the shipping app and the only place product
changes land.
